実装と計測の範囲

固定の計算グラフ

学習による近似は使いません。同じONNXからCPU用WASMとGPU用コードを生成します。未対応の入力はエラーとして報告します。

全入力を保持

連続seedを事前に間引きません。終了済みの戦闘は状態を保持し、上限で継続中の戦闘も結果に残します。

この端末での実測

速度は選択した処理範囲と端末に依存します。CPU/GPU比較は入力ごとの一致確認で、実ROMとの新規照合ではありません。全構成とカメラ全体の実装は継続中です。

戦闘モードは外部ランタイム不要です。単体グラフ・カメラのCPU実行では、一部の宣言済みモデルにONNX Runtime Web 1.31.1をCDNから読み込みます。GPU実行では当該の演算もGPUで処理します。カメラ関連メモリ160ワードのモードは、選択した方式に加え、倍精度演算1モデルをCPUで明示的に実行します。
